# История изменений

## v1.24.0

- Массовая публикация не работала на всех языках сайта, кроме русского и
  английского: кнопку искали по её названию, а по-голландски она называется
  «Bericht maken». Теперь название берётся из словаря самого сайта
  (`common-title__create_post`), так что кнопка находится на любом языке.
- Составной тег больше не рассыпается: подсказки сайта ищутся сначала по
  написанию с «_» — по написанию с пробелами сайт не находит ничего, и
  расширение раньше доходило до Enter, который делит ввод и по пробелу, и по
  «_». Если подсказки нет, тег помечается ошибкой и в форму ничего не
  добавляется: составной тег сайт принимает только из своих подсказок.
- Правый щелчок по тегу в форме копирует его (`stone_wall`), правый щелчок по
  полю тегов вставляет скопированный — удобно переносить теги между файлами.

## v1.23.4

- Репутация берётся оттуда же, откуда её берёт сам сайт: `reputation/ranking`
  возвращает `user_reputation` — нашу строку рейтинга. В профиле
  (`/users/me`) поля репутации нет вообще, поэтому раньше оставалось только
  число, считанное со страницы, а оно относится к текущему раунду и легко
  устаревает.
- В данных для разбора у каждой записи виден адрес ответа и список полей —
  раньше было просто «ответ сайта».

## v1.23.3

- Кнопка обновления репутации показывала старое число: сразу после ответа
  сайта счётчик перезаписывался тем, что нарисовано на странице рейтинга, а
  она не перерисовывается сама. Теперь число со страницы применяется, только
  когда оно действительно изменилось.
- Данные для разбора («Скопировать данные») больше не состоят из одинаковых
  записей: повторы сворачиваются в одну со счётчиком, попадают неудавшиеся
  запросы и текст строки рейтинга, которую расширение приняло за свою.
- В настройках рядом с кнопками появилась версия; по клику она копируется в
  буфер обмена.

## v1.23.2

- Многословный тег больше не рассыпается в форме сайта: пробел там завершает
  тег, поэтому «alisa_(everlasting_summer)» превращалось в «Alisa»,
  «(Everlasting» и «Summer)». Теперь в форму вводится написание с «_», а если
  сайт всё же добавил лишние теги, они убираются.

## v1.23.1

- В поле тегов массовой загрузки пробел сразу превращается в «_»: сайт хранит
  теги с подчёркиванием, и набранное «long hair» уходило как два тега.
  Подстановка подсказки и отправка формы приводятся к тому же виду.

## v1.23.0

- Адаптация под телефон, чтобы дополнение можно было выложить для Firefox для
  Android: скрытое превью открывается долгим нажатием, кнопка обновления
  репутации видна без наведения, настройки раскрываются на весь экран с
  крупными целями, раздел «Клавиши» и задержка для стрелок на сенсорном экране
  скрыты.
- Страница массовой загрузки перестроена под узкий экран и держит не больше
  двух форм одновременно на телефоне.

## v1.22.0

- Массовая загрузка открывает формы по одной с паузой 1,5 секунды, а не пачкой:
  при вставке файла сайт сам запускает автотег и ругался на слишком частые
  запросы.
- Кнопка «Autotag» для выделенных теперь тоже разводит запуски по времени — с
  той же паузой, по очереди.

## v1.21.1

- Починен клик мышью по звёздам и сердечку: с 1.17.0 обработчик падал с
  «t is not a function», потому что локальная переменная закрывала функцию
  перевода. Оценка на сервер уходила, но интерфейс не обновлялся, а клик к
  сайту не пропускался — со стороны это выглядело так, будто оценка не
  ставится.
- Имя `t` больше нигде не используется под локальные переменные, а сборка
  падает, если оно появится снова.

## v1.21.0

- У счётчика репутации при наведении появляется кнопка обновления: она
  спрашивает значение заново, показывает его в тосте и крутится, пока ждёт
  ответ.
- Значение обновляется само, когда открывают боковую панель со счётчиком, но не
  чаще раза в полминуты.
- Обновление по кнопке или при открытии панели перебивает значение, которое
  раньше считалось более надёжным (со страницы рейтинга).

## v1.20.1

- Метка лайков не показывается, когда их ноль.

## v1.20.0

- Количество лайков в правом верхнем углу карточки и отдельная настройка для
  него. Большие числа сокращаются (25.6K), в подсказке — точное значение.

## v1.19.1

- Строки, попадающие в разметку, экранируются (`esc`/`T`): перевод с кавычкой
  больше не может разорвать атрибут вроде `title="…"`. Данные страницы и имена
  файлов в разметку по-прежнему не подставляются — только `textContent`.
- `strict_min_version` поднят до Firefox 140 (Android — 142): именно с этих
  версий поддерживается `data_collection_permissions`, из-за чего валидатор AMO
  выдавал предупреждения.
- В заметках для ревьюера описаны три места с `innerHTML` и почему они
  безопасны.

## v1.19.0

- Подготовка к публикации на addons.mozilla.org: в манифестах Firefox объявлен
  сбор данных (`data_collection_permissions: none`) — обязательное поле для
  новых дополнений.
- Расширение переименовано в «Quick Actions for Sankaku», в описании сказано,
  что оно неофициальное; добавлен `homepage_url`. Имя юзерскрипта не менялось,
  чтобы не сломать обновление у тех, кто уже его поставил.
- `python build.py --source` собирает архив исходников для ревьюеров; из него
  сборка воспроизводится байт в байт.
- Добавлены `docs/REVIEWER_NOTES.md` и `docs/amo-listing.md`.

## v1.18.0

- Общая кодовая база: из одних исходников собираются юзерскрипт для
  Tampermonkey и расширения для Chrome (MV3), Firefox (MV3) и Firefox (MV2).
- `build.py` собирает все цели, подставляет переводы, рисует иконки и проверяет
  результат; `test/` содержит макет сайта для проверки всех режимов доставки.
- В шапке юзерскрипта появились ссылки на обновление: Tampermonkey сам следит
  за новыми версиями.

## v1.17.0

- 26 языков — интерфейс следует языку, выбранному в настройках Sankaku.
- Убрана зависимость от русских и английских подписей сайта: успешная
  публикация определяется по классу плашки, кнопка отправки — по типу.

## v1.16.0

- Метка своей оценки (1–5) на карточке в сетке и переключатель для неё.

## v1.15.0

- Настройки переехали во вкладку «Плагин» на странице настроек сайта.
