# Sankaku: оценки и избранное без открытия поста

Одни исходники — четыре сборки: юзерскрипт для Tampermonkey и расширения для
Chrome (MV3), Firefox (MV3) и Firefox (MV2).

## Сборка

```bash
python build.py          # собрать всё в dist/
python build.py --zip    # ещё и упаковать расширения в архивы
```

Версия задаётся одной строкой в начале `build.py` и попадает и в юзерскрипт,
и во все манифесты.

## Что где лежит

| Путь | Что это |
|---|---|
| `src/core.js` | Всё поведение скрипта. Общий код для всех сборок, работает в контексте страницы |
| `src/loaders/userscript.js` | Загрузчик для Tampermonkey: песочница, `GM_*`, пункт меню |
| `src/ext/bridge.js` | Мост расширения: изолированный мир, хранилище, кнопка на панели |
| `src/ext/background.js` | Фон расширения: клик по кнопке открывает настройки |
| `src/ext/manifest.*.json` | Три манифеста |
| `src/header.txt` | Метаданные юзерскрипта |
| `src/i18n/` | Переводы: `base.json` — порядок строк и английский, `lang_<код>.json` — остальные 24 языка |
| `dist/` | Результат сборки (перезаписывается) |
| `sankaku-quick-actions.user.js` | Копия собранного юзерскрипта в корне — по ней ставят обновление |

## Как ядро попадает в страницу

Ядру нужен контекст самой страницы: оно подменяет `fetch`/XHR сайта и читает
данные React. Способ доставки — единственное, что различается между сборками.

| Сборка | Доставка ядра | Настройки |
|---|---|---|
| Tampermonkey | `GM_addElement('script')` | `GM_getValue` / `GM_setValue`, синхронно |
| Chrome MV3 | content script с `"world": "MAIN"` | `chrome.storage.local`, асинхронно |
| Firefox MV3 | то же (нужен Firefox 128+) | `browser.storage.local` |
| Firefox MV2 | мост вставляет исходник строкой; если CSP запретит — файлом из `web_accessible_resources` | `browser.storage.local` |

Хранилище в расширении асинхронное, а ядро обязано стартовать до первых
запросов сайта. Поэтому оно запускается с настройками по умолчанию и получает
сохранённые отдельным событием:

```
ядро → skq:ready, skq:settings-request → мост
мост → skq:settings-load (JSON) → ядро
ядро → skq:settings-save (JSON) → мост → storage
кнопка расширения → background → мост → skq:open-settings → ядро
```

Те же события использует и загрузчик Tampermonkey, так что ядро не знает, где
оно запущено.

## Установка

**Tampermonkey.** Открыть
[sankaku-quick-actions.user.js](https://raw.githubusercontent.com/MotoIlyuha/sankaku-quick-actions/main/sankaku-quick-actions.user.js)
— Tampermonkey предложит установку и дальше будет сам проверять обновления.

**Chrome.** Скачать `sankaku-chrome-*.zip` из
[Releases](https://github.com/MotoIlyuha/sankaku-quick-actions/releases),
распаковать, затем `chrome://extensions` → «Режим разработчика» → «Загрузить
распакованное расширение». Собранное локально лежит в `dist/chrome`.

**Firefox.** `sankaku-firefox-mv3-*.zip` для Firefox 128 и новее,
`sankaku-firefox-mv2-*.zip` для старых сборок. Распаковать и загрузить через
`about:debugging#/runtime/this-firefox` → «Загрузить временное дополнение» →
`manifest.json`. Временное дополнение живёт до перезапуска браузера; для
постоянной установки нужна подпись на addons.mozilla.org.

Настройки в расширении открываются кнопкой на панели браузера, в
Tampermonkey — пунктом «⚙ Настройки» в меню скрипта. На странице настроек
сайта и там, и там появляется вкладка «Плагин».

## Меню сайта

Вкладка «Меню сайта» в настройках плагина: каждому пункту бокового меню можно
дать своё название, скрыть его и назначить клавишу перехода (подменю «Посты» —
Ctrl+1…6, «Книги» — Alt+1…6, по умолчанию выключены). Рядом с «Избранными» и
«Моими» постами и книгами показывается их количество, рядом с «Рейтингами» —
репутация; счётчики обновляются при открытии меню.

Там же две клавиши для самого меню: одна открывает и закрывает его (можно
назначить одну клавишу без модификаторов), вторая настройка показывает меню,
пока зажат Ctrl или Alt, и убирает его, когда клавишу отпустили. Обе по
умолчанию выключены. Пока модификатор зажат, рядом с пунктами видно, какую
цифру нажать, — это отдельная галочка под второй настройкой.

Переименовать можно и прямо со страницы: заголовок при наведении обведён
рамкой, по клику становится полем ввода, а изменённый текст сохраняется
галочкой. Если у заголовка есть свой пункт меню, меняется он же.

Столбцы таблицы подписаны строкой, которая держится наверху при прокрутке, а
кнопка «Сохранить» — в подвале, прилипшем к нижнему краю.

В шапке страниц появляются кнопки перехода: на «Моих постах» — «Массовая
загрузка», на «Загрузить пост» и «Массовой загрузке» — «Мои посты», на
«Загрузить книгу» — «Мои книги». Кнопка копируется с кнопки сайта (когда та
есть в шапке), а подпись берётся из меню — вместе с переименованием.

Пункты находятся по атрибуту `data-test` — это ключ из конфигурации сайта
(`post-indexes`, `my_posts`, `menu_favorites-book`…), а исходные названия
берутся из словаря сайта в `window.__PRELOADED_STATE__`. Поэтому переименование
работает на любом языке и меняет заодно заголовок страницы.

## Телефон

Расширение помечено совместимым с Firefox для Android (`gecko_android`,
версия 142 и новее). На сенсорном экране:

- скрытое превью открывается долгим нажатием по карточке, а не наведением;
- кнопка обновления репутации видна всегда, без наведения;
- окно настроек раскрывается на весь экран, цели крупнее, раздел «Клавиши» и
  задержка для стрелок скрыты — клавиатуры там нет;
- массовая загрузка держит не больше двух форм одновременно, даже если в
  настройках стоит больше: каждая форма — целая копия страницы сайта.

В левом верхнем углу карточки видны средняя оценка поста и своя оценка, в
правом — количество лайков; каждая метка отключается в настройках, а превью
рядом с ними позволяет перетащить метки в любой угол (в одном углу их может
быть несколько). Свою оценку можно показывать числом или звёздами.

Клавиша «B» открывает сразу все скрытые превью на странице и тем же нажатием
возвращает их обратно. Карточка под мышью обводится так же, как выбранная
стрелками.

Чего на телефоне нет: горячих клавиш (1–5, F, C, E, B), выбора карточек
стрелками и показа превью по наведению.

## Выпуск версии

1. Поднять `VERSION` в `build.py`, добавить раздел в `CHANGELOG.md`.
2. `python build.py` и закоммитить в том числе пересобранный
   `sankaku-quick-actions.user.js` — по нему обновляется Tampermonkey.
3. `git tag v1.18.0 && git push origin v1.18.0`.

Дальше работает `.github/workflows/release.yml`: собирает все цели, сверяет тег
с версией, проверяет, что закоммиченный юзерскрипт совпадает с исходниками, и
создаёт релиз с файлом скрипта и тремя архивами расширений. Описание релиза
берётся из раздела `CHANGELOG.md` для этой версии.

## Публикация на addons.mozilla.org

На AMO подаётся сборка **MV3** (`dist/firefox-mv3`): она не дублирует ядро, в
отличие от MV2, где оно лежит и строкой в мосте, и файлом. MV2 остаётся для
самораспространения и старых версий Firefox.

К заявке нужны три вещи:

1. **Архив исходников** — `python build.py --source` кладёт
   `dist/sankaku-source-<версия>.zip`. Из него сборка воспроизводится командой
   `python build.py --zip` без интернета и сторонних зависимостей.
2. **Заметки для ревьюера** — [`docs/REVIEWER_NOTES.md`](docs/REVIEWER_NOTES.md):
   что делает дополнение, зачем ему контекст страницы и подмена `fetch`, почему
   данные никуда не уходят, как собрать пакет.
3. **Тестовый аккаунт на сайте** — без входа не проверить ни оценки, ни
   избранное, ни загрузку. Логин и пароль вписываются в форму подачи.

Текст карточки, категории и остальные поля — в
[`docs/amo-listing.md`](docs/amo-listing.md). Сбор данных объявлен в манифесте
(`data_collection_permissions: none`), это обязательное поле для новых
дополнений с 3 ноября 2025 года.

Документации у Sankaku нет, поэтому список адресов собран из кода самого

## Проверка на макете

Сайт закрыт для автоматизации, поэтому рядом лежит макет его разметки и API:

```bash
python build.py
python test/server.py 8766
```

Дальше `http://localhost:8766/<язык>/...` — например `/ru`, `/ja/settings`,
`/ru/posts/upload#skq-mass`, `/ru/reputation`. Параметр `?ext=` переключает
режим доставки ядра, файлы берутся прямо из `dist/`:

| Адрес | Что проверяется |
|---|---|
| без параметра | юзерскрипт (`GM_*`) |
| `?ext=main` | расширение с `world: "MAIN"` (Chrome MV3, Firefox MV3) |
| `?ext=1` | тот же мост без поддержки `world: MAIN` — вставляет ядро сам |
| `?ext=mv2` | мост Firefox MV2: ядро строкой |

Режим запоминается на вкладке, чтобы фреймы формы загрузки открывались так же.
`?sitelang=nl` переключает язык самого макета: кнопка «Создать пост»
называется «Bericht maken», и видно, что расширение находит её по словарю
сайта, а не по словам.
В режиме расширения `chrome.storage` подставной и асинхронный, а
`window.__extMessage({skq:'open-settings'})` заменяет клик по кнопке на панели.

`node test/check.js sankaku-quick-actions.user.js` проверяет, что ядро
самодостаточно (его исходник должен выполняться отдельно от загрузчика).

## Переводы

155 строк на 26 языков. Ключ строки — её русский текст, поэтому в коде видно,
что переводится. Файлы `lang_*.json` пронумерованы по порядку из `base.json`;
сборка падает, если в каком-то языке не хватает строки или не совпадают
подстановки вроде `{n}` и `{key}`.

Язык берётся из настроек сайта: сначала префикс в адресе (`/ja/`, `/zh-tw/`),
затем `<html lang>`, затем хранилище сайта, затем язык браузера.
